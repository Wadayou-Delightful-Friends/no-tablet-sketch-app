# 開発ドキュメント

人間と AI が**同じものを読んで動く**ためのドキュメント置き場。
会話や指示のたびに繰り返している約束事・手順は、ここに書いて共有する。

## 構成

```
docs/
  README.md   # この導入。行動指針と各フォルダの案内
  rules/      # 約束事の各論（例: 命名規則、テスト方針）。1 ファイル 1 テーマ
  skills/     # 定型作業の手順書（例: リリース手順、環境構築）。1 ファイル 1 作業
```

`skills/` はまだ空。必要になったときに書く。

## 行動指針

### 人間も AI も共通

- 小さく頼み、小さく作る。1 回の依頼・変更は 1 目的
- 推測で進めない。曖昧なら選択肢を挙げて確認する
- 「完了」は動作確認とセット（`pnpm build` / `pnpm lint` が通ること）

### 人間側

- 同じ指示を 2 回書いたら、`rules/` か `skills/` への昇格を検討する
- AI の報告を鵜呑みにせず、差分をレビューしてからコミットする

### AI 側

- [AGENTS.md](../AGENTS.md) の約束事に従う
- ここに書かれていないルールを勝手に発明しない。迷ったら提案して確認する

## ルール・スキルの増やし方

- 1 ファイル 1 テーマで短く。禁止事項の羅列ではなく判断基準を書く
- 書いたら PR に含めて、他の開発者が気づける形で共有する
